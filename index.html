💾Backup dos seus dados

Salve uma cópia de todos os registros, ganhos, gastos, pagamentos, faturas e eventos em um arquivo no celular. Você poderá carregar esse arquivo para recuperar os dados depois ou em outro aparelho.

Dica: faça um novo backup sempre que fizer mudanças importantes. O arquivo de backup não é atualizado sozinho; o aplicativo continua salvando os dados neste navegador.
